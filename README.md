# YouTube Style Lab

Paste a YouTube video or channel. The YouTube Data API loads the details, Gemini watches the video, and you get its visual style plus shot-by-shot image and video prompts (with Hindi voiceover lines).

**Open the app:** https://ritesh021996gaonkar-ai.github.io/Youtube-analytic/

Keys (YouTube Data API + Gemini) are entered in the app and stored only in your browser.
